# Short Kurti Store

A modern, fully responsive e-commerce frontend for a women's short kurti brand. Built with **Next.js 15 (App Router)**, **Tailwind CSS**, **Framer Motion**, **Zustand**, and **React Icons**.

## Features
- Premium feminine UI with blush, lavender, and beige palette
- Sticky animated navbar with mobile drawer and live cart count
- Home with hero, trending categories, featured products, reviews, newsletter
- Collection page with filters (size, color, price, category) & sort
- Product details page with gallery, size/qty, related carousel
- Cart page with coupons and order summary
- Wishlist, Auth (login/signup), About, Contact pages
- Quick view modal, skeleton loaders, dark/light mode, micro-interactions

## Getting started
```bash
npm install
npm run dev
```
Open http://localhost:3000
